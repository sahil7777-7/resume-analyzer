# Reframe

An AI-powered resume analyzer that helps you understand what is working in your resume and what can be improved for the role you're targeting.

## 🚀 Live Demo

https://resume-analyzer-3lo8.onrender.com/

## 📌 About

Reframe lets you upload your resume in PDF format and optionally provide the job role or description you're applying for.

It then uses AI to analyze your resume and gives practical, role-specific feedback instead of just pointing out generic mistakes.

## ✨ Features

- Upload resumes in PDF format
- AI-powered resume analysis
- Add an optional job role or description
- Get role-specific feedback
- Identify resume strengths and weaknesses
- Get practical improvement suggestions
- Clean and responsive UI
- File validation and error handling
