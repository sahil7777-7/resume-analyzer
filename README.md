# Reframe

Reframe is an AI-powered resume analyzer that provides clear, actionable, and role-specific feedback to help job seekers improve their resumes and increase their chances of getting interviews.

## Features

- Upload resumes in PDF format
- Analyze resume content using AI
- Add an optional job description
- Get role-specific feedback
- Identify resume strengths and weaknesses
- Receive practical improvement suggestions
- Clean and responsive user interface
- File validation and error handling

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- LangChain
- OpenRouter 
- Large Language Models
